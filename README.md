## Projects

Larger projects have their own repositories so that they can be documented and developed properly.

### Network Asset Inventory

A Python command-line network asset discovery tool that I built to improve my understanding of TCP/IP networking, Python sockets, concurrency, testing and network reconnaissance.

The tool currently supports:

- IPv4 host and small subnet scanning
- TCP port scanning
- Concurrent connection attempts
- Host responsiveness detection
- Open-service inventories
- JSON and CSV reports
- Automated testing
- GitHub Actions continuous integration

Version `v1.0.0` contains 42 automated tests and is my first completed portfolio release.

Repository:

https://github.com/JakeOBrien-Dev/network-asset-inventory

### Python Log Analyser

My first cyber-security focused Python project.

The script:

- Reads authentication log files
- Counts successful and failed login attempts
- Tracks failed attempts by IP address
- Flags suspicious IP addresses based on a threshold

Repository:

https://github.com/JakeOBrien-Dev/python-log-analyser
